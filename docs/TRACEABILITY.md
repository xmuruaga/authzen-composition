# Traceability: profile requirements to tests

Each MUST and MUST NOT in `authzen-composition-profile-1_0.md` has a row, and so
does each SHOULD that the reference implements.
**Shown** means the reference implementation demonstrates the property, and the
row cites the tests that do. **Deployment** means the requirement binds a
production deployment and the in-memory reference cannot demonstrate it; the
row says what is and is not tested; some such rows cite no test (one order per
Mission, delegation, designation per Mission, retention and tombstones, a class
the agent could have chosen, what the PEP performs, Search, the formal basis)
or only an end-to-end scenario (a pinning read served by the History Authority
itself, an expired Mission credential).
